# آن AI

مساعد ذكي مخصص لـ **آن coffee** — شمال محايل عسير.

## التشغيل
```bash
npm start
```

المسارات:
- `/` واجهة العميل
- `/admin` لوحة الإدارة
- `/health` فحص الخدمة

## متغيرات Railway
- `ADMIN_PIN`: رمز دخول لوحة الإدارة.
- `PORT`: يحدده Railway تلقائيًا.

النسخة الأولى تعمل من قاعدة معرفة مؤكدة ولا تخترع الأسعار أو أوقات العمل أو تفاصيل لم تعتمد بعد.

## بطاقة Apple Wallet (`/wallet`)
صفحة `/wallet` تعرض بطاقة آن coffee وفيها باركود الموقع، وزر «أضف إلى Apple Wallet» يحمّل ملف `.pkpass` من `/api/pass`.
Apple لا تقبل أي بطاقة إلا موقّعة بشهادة من حساب Apple Developer، فالزر يبقى معطّلًا حتى تضاف المتغيرات التالية:

| المتغير | القيمة |
|---|---|
| `APPLE_PASS_TYPE_ID` | معرّف البطاقة، مثل `pass.com.anncoffee.card` |
| `APPLE_TEAM_ID` | رمز الفريق (10 خانات) من حساب المطوّر |
| `APPLE_PASS_CERT` | شهادة Pass Type ID بصيغة PEM (أو base64 لها) |
| `APPLE_PASS_KEY` | المفتاح الخاص لها بصيغة PEM (أو base64) |
| `APPLE_WWDR_CERT` | شهادة Apple WWDR (G4) بصيغة PEM (أو base64) |
| `APPLE_PASS_KEY_PASSPHRASE` | اختياري، إذا كان المفتاح بكلمة مرور |
| `SITE_URL` | اختياري، رابط الموقع الذي يفتحه الباركود |

الخطوات:
1. اشترك في Apple Developer Program.
2. من Certificates, Identifiers & Profiles: أنشئ **Pass Type ID** ثم أنشئ له شهادة (Certificate) ونزّلها.
3. حوّل الشهادة والمفتاح إلى PEM:
   `openssl pkcs12 -in pass.p12 -clcerts -nokeys -out cert.pem` و `openssl pkcs12 -in pass.p12 -nocerts -nodes -out key.pem`
4. نزّل شهادة **WWDR G4** من صفحة Apple للشهادات وحوّلها: `openssl x509 -inform der -in AppleWWDRCAG4.cer -out wwdr.pem`
5. أضف المتغيرات في Vercel أو Railway (يمكن لصق المحتوى كما هو أو `base64 -w0 file.pem`)، ثم أعد النشر.

لا ترفع ملفات `.pem` أو `.p12` إلى المستودع. الباركود الحالي يفتح `https://ann-ai-lac.vercel.app`، وملفاته `public/qr.svg` و`public/qr.png`.

## الطلبات من الموقع (سلة، طاولات، استلام، توصيل)

**مسار العميل:** يضغط «أضف» على أي صنف، ثم يفتح السلة (الكميات وملاحظة لكل صنف)، ثم «متابعة الطلب» ويختار داخل المحل (برقم الطاولة) أو استلام من المحل أو توصيل، ويختار طريقة الدفع. بعدها تظهر له صفحة `/order` فيها رقم الطلب والفاتورة وحالة الطلب، وتتحدث تلقائيًا.

**باركود الطاولات:** من `/orders` ثم «باركود الطاولات» تطبع باركود لكل طاولة. كل باركود يفتح `/?table=N`، فيدخل الطلب للكاشير برقم الطاولة.

**لوحة الكاشير:** `/orders` (تفتح برمز `ADMIN_PIN`). فيها:
- الطلبات مقسومة حسب الحالة (جديد، قيد التحضير، جاهز، تم التسليم) مع تنبيه صوتي للطلب الجديد.
- زر «تم الدفع» لطلبات الدفع عند الاستلام.
- إيقاف الطلبات أو تشغيلها.
- تبويب لتحديد الأصناف التي نفدت.
- الإعدادات: رقم الواتساب، رسوم التوصيل، طرق الاستلام، وطرق الدفع.

الأسعار تُحسب في الخادم من `data/menu.json`، ولازم تطابق المكتوب في `public/index.html`. كل صنف في الصفحة عليه `data-id` من الملف.

### متغيرات البيئة

| المتغير | لازم؟ | الوظيفة |
|---|---|---|
| `ADMIN_PIN` | نعم | رمز دخول لوحة الطلبات والإدارة |
| `SHOP_WHATSAPP` | مستحسن | رقم واتساب المحل، يوصل عليه نص كل طلب (يقدر يتغير من اللوحة إذا قاعدة البيانات مربوطة) |
| `UPSTASH_REDIS_REST_URL` و `UPSTASH_REDIS_REST_TOKEN` | نعم على Vercel | قاعدة بيانات تحفظ الطلبات والإعدادات. خطتها المجانية تكفي. تقبل أيضًا `KV_REST_API_URL` و `KV_REST_API_TOKEN` من تكامل Upstash في Vercel |
| `DELIVERY_FEE` | لا | رسوم التوصيل الافتراضية بالريال |
| `ORDERS_OPEN` | لا | `false` يوقف الطلبات (ويتغير أيضًا من اللوحة) |
| `MOYASAR_PUBLISHABLE_KEY` و `MOYASAR_SECRET_KEY` | للدفع الإلكتروني | مفاتيح بوابة ميسّر (Apple Pay، مدى، بطاقات، STC Pay) |
| `APPLE_PAY_DOMAIN_ASSOCIATION` | لـ Apple Pay | محتوى ملف التحقق من الدومين الذي تعطيك إياه ميسّر. يُقدَّم على `/.well-known/apple-developer-merchantid-domain-association` |

**حماية من ضياع الطلبات:** إذا ما فيه قاعدة بيانات ولا رقم واتساب، يوقف الموقع استقبال الطلبات تلقائيًا.
- بدون قاعدة بيانات على Vercel: الطلبات تمشي عبر واتساب فقط، ولوحة الطلبات تكون مؤقتة.
- على Railway أو التشغيل المحلي: تنحفظ الطلبات في ملف `data/orders.local.json`.

### تفعيل الدفع الإلكتروني (ميسّر)
1. سجّل حساب تاجر في moyasar.com وفعّل الحساب.
2. انسخ المفتاح العام (pk_live_…) والمفتاح السري (sk_live_…) إلى متغيرات البيئة. للتجربة استخدم مفاتيح test.
3. لـ Apple Pay: من لوحة ميسّر سجّل الدومين، وانسخ محتوى ملف التحقق إلى `APPLE_PAY_DOMAIN_ASSOCIATION`.
4. يتحقق الخادم من كل عملية دفع عند ميسّر: المبلغ والعملة ورقم الطلب. وبعدها يتحول الطلب إلى «جديد» ويظهر للكاشير.
